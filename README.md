# 甜橙谷塔防

原生 HTML5 Canvas 塔防游戏，无第三方运行依赖。

## 内容与模式架构

地图、事件、敌人和关卡配置已迁入 `game-content.js`，通过 `ContentRegistry` 注册和校验；`GameSession` 统一管理无尽与闯关模式。目前默认界面仍进入无尽模式，同时已经准备三章闯关数据和四张独立路径地图。未来关卡选择界面可通过 `GameApp.startMode('campaign', levelId)` 启动关卡。

完整模块边界与新增内容示例见 [GAME_ARCHITECTURE.md](GAME_ARCHITECTURE.md)。
阵营、职业、唯一形态计数与新增羁绊规范见 [SYNERGY_ARCHITECTURE.md](SYNERGY_ARCHITECTURE.md)。

## 隔离环境与启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m http.server 4174
```

浏览器访问 `http://127.0.0.1:4174`。

## 塔领域模型

塔已迁移为面向对象的领域模型：不可变蓝图由 `TowerCatalog` 管理，战场状态由 `Tower` 实例管理，索敌方式通过可注册的攻击策略扩展。79 种现有塔全部经过同一工厂创建和校验，设计说明见 [TOWER_ARCHITECTURE.md](TOWER_ARCHITECTURE.md)。

无需安装测试框架即可运行回归：

```bash
node tests/content-system.test.js
node tests/tower-system.test.js
node tests/enemy-system.test.js
node tests/evolution-system.test.js
node tests/synergy-system.test.js
node tests/game-smoke.test.js
```

## 敌人领域模型

敌人由不可变族类蓝图、词缀目录、实例状态控制器、统一工厂和波次生成导演组成。当前族类包括苔芽精、棘背兽、流光蛾、岩壳卫、沼泽祭司、腐根暴君和烬角鹿王；生命、护甲、属性抗性、控制抗性、持续伤害、再生、狂暴、移动与逃脱均由敌人实例负责。

## 操作

- 拖动炮塔改变位置。
- 同形态守卫有两种培养方式：同等级触发“共鸣合成”，除被吞噬等级外额外获得 50% 共鸣灵蕴，效率最高；更低等级塔则可被“培养吞噬”，按自身等级转化为灵蕴，效率较低但随时可用。两条路互补，不再产生指数级素材墙。
- 选中主塔后点击“灵蕴祭炼”，可把任意其他路线、任意等级的塔转化为灵蕴。进化塔和融合塔的祭炼价值更高，但会永久失去该塔，适合在“多塔协同”和“单核突破”之间做风险决策。
- 每波结束后，当前培育方针会自动结算，4 秒后自动开始下一波；“提前开波”只用于跳过倒计时。到达 Lv.5 或 Lv.10 决策节点时，进化选择会暂停倒计时。
- 培育不再以反复点按为主循环：共生培育会均养低级守卫并强化已激活羁绊；主脉培育会把资源集中到指定核心并强化核心、削弱辅塔；封存共鸣不会消耗库存，而是按库存灵蕴提供全队增伤。三种方针可在战斗中随时规划，本波锁定不变，波末结算并在下一波生效，避免靠卡秒切换套利。
- 阵容采用“阵营 + 职业”双羁绊：金/火/土属于烈铸盟，木/水/风属于生息庭，阴/阳/雷属于天象仪；攻击方式又对应破军、贯星、引脉、燎原和神谕。只有不同塔形态计数，重复堆同一种塔不会虚增羁绊，分支和双阵营融合塔因此拥有长期阵容价值。
- “灌注至节点”和“灵蕴祭炼”保留为阵容纠偏工具，系统会在 Lv.5、Lv.10、Lv.15 或 Lv.20 自动停下，不再要求玩家持续逐枚点击灵种。
- 仓库压缩不会损失培养价值：Lv.1-Lv.5 灵种分别可灌注 1/2/4/8/16 点灵蕴，库存界面会直接显示当前总灵蕴。
- 炮塔会自动攻击道路上的敌人；所有成长资源统一由战斗和波次结算注入世界树。
- 攻击按职责使用不同交付方式：金、土近战挥砍或重砸，木、风沿真实攻击轴贯穿，水、阴、雷逐段连锁，火系抛射轰炸，阳系落点照射，毒系分支持续降雨，融合塔展开全域阵法。只有普通远程和弹幕专精路线会形成多波齐射。
- 燃烧、中毒、冻结、眩晕、击退、破甲和易伤会显示战场标记与剩余时间，控制效果可直接从敌人的动作和状态图标辨认。
- 炮塔达到 Lv.5 时从三张主路线卡牌中选择进化，Lv.10 时从该路线的三张专属分支卡牌中选择进阶；最高等级为 Lv.20，五灵塔可通过五行阵型合成。
- 一键合成会整编所有可培养的同形态守卫，进化选择期间游戏会自动暂停；批量整编不会越过待确认节点。
- 世界树使用统一的成长槽，切换根系不会损失或套利进度；三种根系通过吸收效率和直接培育等级形成差异。精炼根系会消耗略高的节点，但直接产出 Lv.3-5。
- 战场会轮换丰饶、迷雾、兽潮、遗物等事件；连续击杀可以积累连击分数。
- 击败敌人会为“橙光爆发”充能；充满后可点击战技按钮（或按空格）对全场敌人造成伤害并眩晕。
- 击杀与波次奖励会化为灵力并被世界树自动吸收，进度满后自动凝结灵种，无需重复点击购买。
- 世界树有繁育、均衡、精炼三种根系策略；它们分别偏向快速产量、稳定成长和直接产出高等级灵种。
- 灵种先进入仓库，不会直接挤占地图；仓内会优先整编到 Lv.5 节点。出仓后可把低级灵种直接注入场上主塔，培养到 Lv.5/Lv.10/Lv.15 时分别触发觉醒、分支和终极被动节点。
- 战场最多同时指挥 8 座塔，但塔资产没有 8 座硬上限；普通塔可撤回灵种仓重新整编，进化塔可撤回待命塔仓并完整保留等级、路线和形态，之后可重新部署。
- 整备阶段点击场地罗盘可以切换已解锁战场；不同战场拥有独立色彩、属性增益、敌人速度和波次奖励，第 2/4/6 波依次开放。
- 选中进化塔时，地图会显示相关隐藏阵式的元素位置；完成特殊摆放可发现隐藏塔，古碑残句会提供轮换线索。

技术规划见 [ROADMAP.md](ROADMAP.md)。当前版本已加入面向对象的塔领域模型、数据驱动的进化分支、统一特效队列上限和 Web Audio 音效总线；后续内容增长到多关卡和大量资源时再迁移到 Vite + TypeScript。
