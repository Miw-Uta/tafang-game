# 甜橙谷 · 黑潮纪事

原生 JavaScript / HTML5 Canvas 单机塔防。战役包含七幕、20 关和 85 波敌军，从林地来信推进到世界树之心；每关有战前剧情、波间通信、独立配给、路线安排、两项挑战和胜败后记。首页直接进入战役地图，逐关解锁，最多获得 60 颗守护之星。

## 2.0 重构

新增定点战术 Q/W/E、五类首领预警与可打断技能、四种剧情终章、七幕根脉路线图、森林主视觉、完整战场适配、五步操作教学、键盘布阵与原创程序配乐。原有战役、成长与存档保留并进行联动回归。

Windows 便携包位于 `release/Orangewood-2.0.0-win-x64.zip`；解压整个目录后运行 `Orangewood.exe`，无需安装 Node.js。桌面菜单支持完整存档导入、导出和导入前备份。Windows 当前为交叉构建，原生验收和 Steam 提交尚未完成，具体边界见 [RELEASE.md](RELEASE.md)，本轮数据与未验收项目见 [FINAL_QA.md](FINAL_QA.md)。

## 开发与试玩

需要 Node.js 22.12.0 或更新版本。

```bash
npm ci
npm start
```

访问 http://localhost:4175。端口占用时可以使用 `npm start -- 4176`。大厅提供无尽远征、20 关战役和开发者模式入口；开发者模式可直接验证守卫、敌人与进化流程。

## 构建与发布

```bash
npm run build
npm run preview
```

`dist/` 是静态发布目录，可部署到支持静态文件的 HTTPS 站点。正式运行不需要 Node.js、CDN 或外部字体服务。构建包含本地图片、中文字体、Lucide、Tween.js 及对应许可文件，为业务脚本和样式生成内容哈希查询参数，并生成 `release.json`。

`dist/_headers` 适用于支持该格式的静态托管商；其他服务器需按平台方式配置响应头。`scripts/serve.js` 用于本地开发和预览。此仓库生成发布包，不自动部署到公网。

## 战役与策略

- 三档难度：叙事、标准、精锐（敌军生命 +45%）。出征选择灵种、战技充能或伤害支援；灵种支援提供 2 枚 Lv.2 灵种，偏向提前铺场而不是直接跳级。
- 每波结束可以选择援军、修复或充能，整备阶段由玩家决定何时开波。无尽模式仍保留四秒自动推进。
- 战役采用固定敌群与词缀编排，首领只在指定位置出现。点击“本关挑战”旁的望远镜，可查看各波真实数量、路线比例、词缀及反制情报。
- 每关通关获得一星，另外两星依据实际操作目标结算，包括合成、连击、谱系、控制、重部署、集火首领、地图目标与羁绊。修复生命不会抹去已记录的损伤。
- 每关有一场独立的战地抉择，共 20 场、40 个结果。选项带有收益和代价，实际改变后续敌群生命、伤害、射程、控制时间、灵力或战技威力；其中 8 关改变敌群分路。选择随本关保存，通关后可在“根脉纪事”回顾。
- 四种战场、双路来敌、属性增益、特殊部署点与可清理地物共同影响布阵。战役固定本关战场，无尽模式逐步开放地图切换。
- 79 种塔形态共用塔领域模型，包含主路线、分支和特殊融合。阵营与职业羁绊只计算不同形态，鼓励混合阵容。
- 溯潮典狱长、霜月司钟者、蚀心树灵加入首领阵容：镜面护盾、群体保护、半血变相与控制免疫要求不同的应对方式。
- 首领眩晕不能连续刷新，结束后有 1.5 秒恢复窗口；冻结不会附赠眩晕，护盾击退免疫实际阻止位移。影刃围绕射程内目标攻击，总伤害遵循四段各 25% 的预算。

## 操作与成长

- 点击灵种后点击部署格；拖动守卫调整站位，同形守卫可合成。最多同时部署八座守卫，撤回的进化守卫保留等级、路线和形态。
- 整备时可以自由调整；战中移动和重部署需要 2 秒架设，保留更长的剩余冷却，并取消未发出的攻击。首关提供 Lv.3 初始守卫，让三种支援都有稳定开局。
- 战场可放大到 3 倍；手形工具切换平移，完整战场按钮恢复全景。放大不改变部署坐标，适合手机精确布阵。
- 同级合成直接升一级，较低等级同形素材转为成长进度。Lv.5 选择主路线，Lv.10 选择专属分支，最高 Lv.20。一键合成会在进化选择处停下，可撤销最近的一次一键合成。
- 战役 Lv.5 始终提供全部五行路线及一条随关卡、波次轮换的稀有路线；Lv.10 提供所属谱系的全部分支。无尽模式保留随机候选。
- 灵力达到根系阈值后生成抽芽选项，按三次灵种、一次培育循环，各根系独立推进等级序列。培育达到阈值会升级并触发进化；无有效目标时资源保留。转换消耗 20 灵力，互换未领取选项的灵种/培育类型，等级与付费序列保持不变。
- 繁育、均衡、精炼影响灵力吸收、灵种序列、伤害与攻击间隔，只能在整备时切换。
- 选中守卫后可切换前方、后方、最强、最弱、反制索敌；点击敌人下达集火，右键或解除锁定按钮取消。连锁、范围和穿透仍保留原有攻击范围。
- Q 缚根结界控制路口；W 橙光战歌提升范围内守卫攻速；E 照夜萤火破盾、增伤并打断首领读条。三者共用 100 点指令能量，暂停与整备不回复，波前续战保留冷却。按键进入瞄准后可点击、触屏或用方向键与 Enter 施法。
- 标准与精锐第 4 关起，首领在地面预警 3 秒后暂时打断范围内守卫攻击；移出圈外或用 E 打断可以反制。叙事难度关闭该机制，详见 [BOSS-ENCOUNTERS.md](BOSS-ENCOUNTERS.md)。
- H 查看操作手册，1–9 选择灵种，K 开启键盘布阵，方向键移动光标，Enter 部署。N 开波、M 合成、R 撤回、F 循环索敌。五步教学按实际完成的操作记录，支持关闭和重看。
- 橙光爆发在充满后对全场造成伤害与眩晕。爆发直接击杀不再给自身充能，精锐难度的额外敌军血量不再抬高爆发伤害。空格释放战技，P 暂停，Esc 取消部署；弹窗与输入控件不会触发后台快捷操作。
- 暂停、速度、音效、减少动态、守卫档案和敌军情报可在游戏内使用。支持鼠标与触屏，手机界面将阵容信息排列在战场下方。

音乐与环境声使用本地 WebAudio 生成，首次操作后播放，暂停或切换后台时停止。设置中可以分别调整音量或静音。

## 存档

战役进度、最佳成绩、星级、剧情选择和设置保存在当前浏览器的 `localStorage`。旧版通关记录会保留，设置中可以导出战绩 JSON；当前不提供账号或跨设备同步。

战役另保存一份正在进行的波前阵容：塔等级与形态、索敌、灵种与待命塔、成长进度、灵力、战技充能、地图清理、任务统计、难度、支援、补给及剧情选择均可恢复。刷新或返回地图后，“续战”回到该波开战前的整备阶段，不保留波中敌人和弹体。已经领取的补给与选择不会重新发放。新开战役会替换这份续战，胜利后清除；失败仍可从最后一波的整备点重试。未完成进化选择时保留此前有效存档。

存档带版本和字段校验，异常数据不会覆盖最后一份有效备份。浏览器禁用存储时仅在当前页面保留内存记录，关闭后丢失。

## 验证

```bash
npm test
npm run simulate
npm run simulate -- --support power
npm run simulate -- --support charge --seed 42
npm run simulate -- --choice second --support power
npm run balance
```

单元与集成回归覆盖内容校验、塔和敌人规则、进化、羁绊、存档、任务计分、战役流程、经济和重复结算。

`scripts/simulate-campaign.js` 使用真实战斗引擎，以合法部署、合成、提供的进化选项、波间补给和战技运行全部 20 关。默认标准难度、禁用转换，可用 `--level worldTree` 指定关卡、`--seed` 改变战斗随机序列、`--json` 输出详细记录。支持 `--strategy mixed|fire|water|metal|wood|earth|base`、`--growth balanced|sprout|refine`、`--difficulty story|normal|veteran`、`--no-surge`。单系策略保留关卡自带的初始守卫；输出累计生命损失、最终阵容、实际候选与进化选择。脚本只预置解锁记录，不提高伤害、不修改敌方生命、不强制胜利。自动布阵通关不能替代真人难度和趣味性测试。

`npm run balance` 对四个代表关卡执行六类阵容对照，生成 `artifacts/balance-audit.json`，包含源码哈希、参数和逐波记录。设计说明与本轮结论见 [BALANCE.md](BALANCE.md)。

浏览器检查需另行准备兼容当前 Node.js 的 Playwright 与 Chromium，先构建并启动预览，再运行：

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
PLAYWRIGHT_BROWSERS_PATH=/absolute/path/to/browsers \
node scripts/verify-browser.js
```

该脚本检查 1440、768、390 像素宽度，阻断外站请求，验证图片、Canvas 像素、缩放与平移、放大后的实际点击部署、索敌、敌军移动、弹窗暂停、奖励、剧情抉择、刷新后的波前续战、纪事和下一关，并生成截图。结算界面采用结束状态夹具，战斗可通关性由独立模拟检查。浏览器检查范围为 Chromium，不代表全部设备与浏览器兼容性结论。

## 代码与资源

- `game-content.js`：地图、事件、敌军、20 关剧情与配给。
- `campaign-system.js`：挑战跟踪与星级；`content-system.js`：注册表、会话、进度。
- `campaign-ui.js` / `campaign-ui.css`：战役地图、整备、补给、结算、设置和档案。
- `story-content.js` / `story-system.js`：20 场剧情抉择、选择校验与战斗效果。
- `checkpoint-system.js` / `campaign-save.js`：续战存档校验、保存与引擎恢复。
- `battle-camera.js` / `battle-camera.css`：战场缩放、平移和精确输入。
- `tactics-system.js` / `tactics-ui.js`：共享指令能量、定点施法与瞄准操作。
- `boss-system.js` / `boss-ui.js`：首领预警、攻击打断、闪避和破绽。
- `chronicles-system.js`：四种终章与历史选择回响。
- `guardian-renderer.js`：九种谱系轮廓、分支印记与六类融合的原生 Canvas 角色绘制，避免后期守卫依赖系统 emoji。
- `world-renderer.js` / `premiere.js` / `premiere.css`：场景地表、主视觉、战役路线与战场布局。
- `experience.js` / `experience.css`：教学、手册、键盘布阵与声音。
- `desktop/`：离线桌面宿主、协议隔离与完整存档迁移。
- `game.js`：Canvas 绘制、输入、成长、战斗与领域模型接入。
- `tower-system.js`、`enemy-system.js`、`evolution-system.js`、`synergy-system.js`：各自领域规则。
- `resources/scenes/`：从项目实际战场与角色素材导出的预览及头像。
- `resources/vendor/`：Lucide（ISC）、Noto Sans SC（SIL OFL 1.1）；构建时加入 Tween.js（MIT）。许可随发布包附带。Sharp 用于开发期图片处理。

更详细的模块设计见 [GAME_ARCHITECTURE.md](GAME_ARCHITECTURE.md)、[TOWER_ARCHITECTURE.md](TOWER_ARCHITECTURE.md) 和 [SYNERGY_ARCHITECTURE.md](SYNERGY_ARCHITECTURE.md)。
