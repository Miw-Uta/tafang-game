# 甜橙谷塔防

原生 HTML5 Canvas 塔防游戏，无第三方运行依赖。

## 隔离环境与启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m http.server 4174
```

浏览器访问 `http://127.0.0.1:4174`。

## 操作

- 拖动炮塔改变位置。
- 将两个同等级炮塔拖到一起即可合成升级。
- 炮塔会自动攻击道路上的敌人；所有成长资源统一由战斗和波次结算注入世界树。
- 炮塔达到 Lv.5 时从三张主路线卡牌中选择进化，Lv.10 时从该路线的三张专属分支卡牌中选择进阶；最高等级为 Lv.20，五灵塔可通过五行阵型合成。
- 一键合成只处理普通橡果守卫，已进化塔需要手动合成；进化选择期间游戏会自动暂停。
- 世界树使用统一的 100 点成长槽，切换根系不会损失或套利进度；三种根系通过吸收效率与固定产出序列形成差异。
- 战场会轮换丰饶、迷雾、兽潮、遗物等事件；连续击杀可以积累连击分数。
- 击败敌人会为“橙光爆发”充能；充满后可点击战技按钮（或按空格）对全场敌人造成伤害并眩晕。
- 击杀与波次奖励会化为灵力并被世界树自动吸收，进度满后自动凝结灵种，无需重复点击购买。
- 世界树有繁育、均衡、精炼三种根系策略；它们分别偏向快速产量、稳定成长和直接产出高等级灵种。
- 灵种先进入仓库，不会直接挤占地图；仓内两个同等级灵种会自动合成至 Lv.4，点击库存等级后再选择地图空格精准部署，Lv.5 进化仍需在战场完成。
- 战场最多指挥 8 座塔；未进化普通塔可以收回仓库重新整编。
- 整备阶段点击场地罗盘可以切换已解锁战场；不同战场拥有独立色彩、属性增益、敌人速度和波次奖励，第 2/4/6 波依次开放。
- 选中进化塔时，地图会显示相关隐藏阵式的元素位置；完成特殊摆放可发现隐藏塔，古碑残句会提供轮换线索。

技术规划见 [ROADMAP.md](ROADMAP.md)。当前版本已加入数据驱动的进化分支、统一特效队列上限和 Web Audio 音效总线；后续内容增长到多关卡和大量资源时再迁移到 Vite + TypeScript。
